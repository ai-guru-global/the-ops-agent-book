产品定位

QwenWork 是面向个人和组织的 AI 工作平台。用户只需用自然语言描述期望的结果，Agent 就会理解需求、选择合适的能力、处理文件和信息，并交付可继续检查、调整和复用的成果。

国际版提供完整的端到端工作流程：创建账号，进入个人或组织工作空间，启动 Agent 会话，使用文件、技能、连接器、定时任务和网页功能，并管理资产、用量、订阅与成员。

QwenWork 如何工作

1. 使用 Google 账号或邮箱注册、登录。
2. 将 QwenWork 账号关联至阿里云账号。
3. 进入个人或组织工作空间。
4. 描述任务；如有需要，选择模型、添加文件，或启用技能和连接器。
5. 跟踪 Agent 的执行进度并检查中间结果。
6. 预览、下载或继续调整最终交付物。
7. 将可重复执行的工作保存为定时任务。

能力地图

账号、登录与工作空间：建立身份并进入正确的工作空间
工作空间与 Agent 会话：描述工作、跟踪执行并接收交付物
文件、网盘与交付物：提供源材料并管理生成结果
技能：为专业任务增加可复用的方法
连接器：让 Agent 使用已授权的外部服务
定时任务：自动执行周期性工作
网页：创建、发布和管理网站
个人资料、用量与订阅：管理账号信息、语言、积分和套餐
组织工作空间与管理后台：管理成员、资产、用量和组织套餐

语言与支持

国际版支持英文和简体中文界面。
