HOW IT WORKS
Bring advanced agent-based reasoning to the Splunk platform
Splunk AI Assistant chains multiple tools together, validates analysis at each step, and delivers complete intelligence with transparent reasoning.
Accelerate investigations using Agent Mode
With Agent Mode enabled, users enter a prompt, and Splunk AI Assistant will decompose it into a list of parallel tools and skill calls. This includes running event scans, discovering existing content like dashboards, and executing searches within the assistant with summarized findings.
Learn about Agent Mode
See it in action
Discover relevant context quickly
Splunk AI Assistant uses semantic search to help users easily find knowledge objects like dashboards, reports, and datasets in natural language. It uses a vector database to store and retrieve relevant context, such as index metadata, sourcetypes, and user search history, to personalize query generation.
Explore context options
Route prompts to the best-fit model
Model Runtime allows Splunk to determine the best model for each prompt, including models hosted outside of
Splunk Cloud Platform
. AI inferencing done via this method remains free. Users can limit the model to only use Splunk-hosted models, but doing so will disable Agent Mode.
Learn more
Gain more control of the data you collect
Context settings and customization provide more control and visibility into the data that is collected from deployments and allows users to toggle certain collection options for index and sourcetype metadata, user search logs, and knowledge objects.

Splunk AI Assistant FAQs
What is Splunk AI Assistant?
Splunk AI Assistant is our agentic AI-powered user experience that is designed to enhance productivity, effectiveness, and overall digital resilience with the full power of the Splunk Platform.
How does Splunk AI Assistant work?
Splunk AI Assistant helps users with any level of Splunk proficiency find answers from their data in Splunk. The assistant offers bi-directional translation between natural language (NL) and Splunk Search Processing Language (SPL), and can help create searches, understand searches, learn SPL, learn more about Splunk platform products and features, and complete entire tasks.
What data is collected by Splunk AI Assistant?
Splunk AI Assistant collects different data depending on what specific personalization features that the customer has opted into. Opting into the context feature allows Splunk AI Assistant to generate responses that are better tailored to the customer’s specific environment. For full details on what is collected and how that data is stored, please see the
AI service data in Splunk AI Assistant
page.
How can a customer share more about their experience using Splunk AI Assistant or request features and enhancements?
If you want to share your thoughts on Splunk AI Assistant or suggest things you'd like to see in future updates to our team, please submit your ideas at
ideas.splunk.com
.
How much does Splunk AI Assistant cost?
Splunk AI Assistant is available at no additional fee to Splunk Cloud Platform and Splunk Enterprise customers, aside from standard subscription fees.
