Personal Builder ID Pro subscriptions are supported in US East (N. Virginia).

The Amazon Q Developer console and profile are supported in US East (N. Virginia) and Europe (Frankfurt).

Several features are not supported for profiles created in Europe (Frankfurt), including AWS Support chat, resource troubleshooting, .NET transformations, Slack chat, Console Mobile Application, GitLab Duo and Amazon Q for GitHub.
