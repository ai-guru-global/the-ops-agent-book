The reimagined Studio provides feature parity with the existing experience: Agent configuration, tools, agentic workflow management, and analytics.

Admins are currently not able to delete agentic solutions; this will be addressed in a future patch.

The new AI Agent Studio is generally available to customers with the September release on instances running Zurich Patch 13, Australia Patch 6, Brazil EA1 (Sep-24), and above. The Otto AI Agents plugin v9.0.8+ is required.
