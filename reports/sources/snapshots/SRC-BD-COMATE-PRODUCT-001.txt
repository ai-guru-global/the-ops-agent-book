文心快码 (Baidu Comate) 是百度公司倾力打造的一款创新性 AI 编程助手。它深度融合了先进的人工智能技术，为开发者提供贯穿软件开发全流程的智能编码辅助，旨在创造更懂你的下一代编程体验。无论您是编程初学者还是经验丰富的开发者，文心快码都能成为您值得信赖的编程伙伴。
您可以通过在
VSCode
、
JetBrains IDEs
等主流 IDE 中安装 Comate 插件，或直接使用功能强大的独立
AI IDE
来体验文心快码。
核心能力
智能体
文心快码内置强大的编程智能体，能够理解复杂的编程任务，并与开发者协同完成。
多智能体协同
：能够自动将复杂任务拆解，并唤起多个分工明确的子智能体协同处理。通过隔离不同任务的上下文，高效完成更大规模、更复杂的软件工程任务。
自定义智能体
：为特定技术领域或业务场景提供深度优化，弥补通用模型在专业领域的不足。同时支持用户按需定制，满足个性化的编程需求。
领域知识与工具集成：通过
自定义规则（Rules）
与
MCP
配置，可轻松接入企业或个人的领域知识库及第三方工具，增强智能体的专业能力。
代码补全
代码补全
：在您编码时，能够精准理解代码上下文，实时预测并生成从单行到整个代码块的补全内容。
超级代码补全
：能够智能预测您下一步可能需要编写代码的位置，并提供代码改写建议。
行间命令
：在代码编辑区内提供丰富的快捷指令，支持一键完成代码解释、添加函数注释、生成单元测试等高频操作。
Inline Chat (行内对话)：通过快捷键在代码编辑区唤起对话框，使用自然语言即可对当前选定的代码进行重构、优化或调试。
知识增强
文心快码通过自研的上下文引擎，在代码补全与对话中能自动检索并融合当前代码库与相关技术文档知识。这使得生成的代码不仅语法正确，而且更贴合项目规范与开发要求。
模型
文心快码采用百度自研的文心代码大模型作为核心引擎，同时灵活支持接入 DeepSeek、ChatGLM、Kimi 等业界优秀的开源模型，以满足不同场景下的性能与成本需求。
AI IDE
除了作为插件使用，文心快码还提供独立的 AI IDE。它深度整合了代码编辑、智能问答和终端功能，实现了无缝联动，让开发体验更加连贯。此外，IDE 还内置了
前端实时预览、元素级调试
等特色功能。
企业特性
针对企业级应用场景，文心快码推出了完善的企业版解决方案。支持 SaaS、混合云及私有化等多种部署模式。可与企业的统一认证和用户系统无缝对接，提供更强的数据安全保障。内置研发效能度量工具，帮助企业管理者洞察团队开发效率。开放丰富的自定义功能，满足企业特定的开发规范与业务需求。
支持语言、IDE与操作系统
支持 Java、Python、Go、C#、C/C++、JavaScript、TypeScript、PHP、Ruby、Rust、Scala、Kotlin 等主流编程语言。
JetBrains IDEs
IDE 版本：IntelliJ IDEA、PyCharm、GoLand、WebStorm、Android Studio 等 2021.1 及以上。
操作系统：Windows 7 及以上、macOS、Linux。
Visual Studio Code
IDE 版本：1.70 及以上。
操作系统：Windows 7 及以上、macOS、Linux。
Visual Studio
IDE 版本：Visual Studio 2019 与 2022 版本。
操作系统：Windows 10 及以上。
Comate AI IDE
操作系统：Windows 10/11（x64/arm64）, macOS 11.0 或更新版本， Linux glibc >=2.28， glibcxx >=3.4.25(如 Ubuntu 20+， Fedora 36+)。
其他场景
远程开发: 完整支持 Remote SSH、Docker、WSL 等远程开发环境。
Web IDE: 支持在 VS Code WebIDE 中使用，并可通过 Open VSX 插件市场下载。
HUAWEI DevEco Studio: 兼容 JetBrains IDEs 的配置要求。
