Overview
Cloud SRE Agents connects Dynatrace Intelligence to the hyperscaler SRE agents running in your cloud environment. When Dynatrace detects a problem, Cloud SRE Agents evaluates your configured Interaction Profiles, dispatches the problem to matching agents in parallel, and writes their findings back to the Dynatrace problem record. For AWS and Azure, the response includes a suggested remediation path alongside the investigation findings.
The app supports all three hyperscaler SRE agents:
AWS DevOps Agent: investigation and remediation in AWS
Azure SRE Agent: investigation and remediation in Azure
Google Gemini Cloud Assist: incident analysis across GCP
Interaction Profiles define which problems get dispatched to which agents. Each profile combines routing conditions with one or more agent assignments. Profiles can include a monthly duration budget per agent; when the budget is reached, dispatch stops or logs a warning depending on your configuration. The Test mode lets you validate a profile against recent problems before any live dispatch occurs.
Use cases
Automatic multi-cloud routing: direct each problem to the agent that owns the cloud it touches, based on account ID, subscription, project, or resource tag, without manual triage at 2 a.m.
Budget governance: set a monthly duration budget per agent; once the cap is reached, new dispatches stop or log a warning, keeping cloud-side spend inside the boundaries you set.
Tiered investigation by problem type: dispatch agents only for the problem categories that justify it (availability, error, resource contention) and narrow by entity type to focus autonomous work on the infrastructure tiers that matter most.
Audit trail for every autonomous action: the Activity tab records every investigation and mitigation as an expandable timeline card with full agent findings, evidence, and any action taken or recommended.
ROI visibility: the Statistics tab surfaces problems handled, mitigation counts, and satisfaction scores by agent, turning autonomous operations into a number you can show to a leadership team.
Get started
Note:
To install the app via Dynatrace Hub, you first need to subscribe your tenant to a Hub subscription.
Click here to learn more
.
Once you are done and have successfully added the app to your tenant:
Set up (3 min): open the Setup tab and follow the guided flow to install the required IAM policy, service user, and three orchestration workflows.
Connect one agent (1 min): in Configuration, add an agent of any cloud type, paste the endpoint URL and credential from your cloud provider's console, and save.
Add one profile (1 min): create an Interaction Profile with one global filter (for example, Has AWS Resources), assign the agent, and enable the profile.
Validate (30 sec): open Trigger Investigation, pick a recent problem, and run Test (Dry Run). If the profile matches as expected, uncheck Dry Run and dispatch live.
The next matching problem dispatches automatically, and findings appear on the Dynatrace problem screen as each agent completes.
