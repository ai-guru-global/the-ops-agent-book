> **合成演示，不是厂商报价或真实运行结果。** 本文件由 `scripts/cost-model.mjs` 从 `examples/cost/roi-example.json` 的输入重算；原输入的 `derived` 与 `sensitivity` 只用于交叉校验，不参与计算。金额为 USD，周期为年。

- 示例：`ops-agent-event-triage-v1`
- 输入 SHA-256：`98bbb33e2fa3f49173a93724ac7ffab200b00d7afcb43f3207bb7e75f5cdff0b`
- 输入状态：synthetic demonstration, not a vendor claim
- 重算与输入声明的一致性：**全部匹配**

## 2. 单位成本重算

```text
模型 = 20,000/1,000,000×$0.50 + 4,000/1,000,000×$2.00 = $0.0180/event
复核 = 25.00%×10/60×$80.00 = $3.3333/event
风险 = 5.00%×$40.00 = $2.0000/event
可变 = 模型 + 工具 + 复核 + 风险 = $5.4513/event
```

## 3. 收益、ROI 与人工基线交叉校验

- 年解决事件：480；未解决：120。
- 释放容量价值 B = 600×80.00%×1×$80.00 = **$38,400.00**。
- 其他不重叠收益 = **$0.00**；毛收益 = **$38,400.00**。
- 净收益 = B − C = **$7,129.20**；ROI = 净收益/C = **22.80%**。

| 单位经济 | 结果 |
| --- | ---: |
| 每事件全成本（失败事件保留） | $52.12 |
| 每成功事件全成本 | $65.15 |
| 人工基线年成本 | $48,000.00 |
| 未解决事件残余人工成本 | $9,600.00 |
| Agent + 残余人工 | $40,870.80 |
| 基线 −（Agent + 残余人工） | $7,129.20 |

最后一行应等于净收益；它防止只计算机器人成本而漏掉未解决事件的人工成本。**释放容量不等于现金节省**，未兑现时应标注“容量口径”。

## 6. 复核与使用限制

- 检查原输入 18 个 derived 数值、14 个敏感性数值。
- 差异数：0。
- 风险准备只在成本侧计一次；不得在收益侧重复扣同一期望损失。
- 同一人工小时不得同时计为容量、Toil 和 MTTR 人工收益。
- 固定成本已按年给出；实施/迁移/爬坡已在首年摊销，不重复计入。
- 采购应替换为合同价格、真实事件量、审计账单、人工基线与退出成本，并保留悲观/基准/乐观情景。
